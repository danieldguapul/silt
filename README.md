# Silt

A warm, muted dark theme for [Omarchy](https://github.com/anomalyco/omarchy), inspired by earthy tones and overcast landscapes.

## Palette

| Role       | Hex       |
|------------|-----------|
| Background | `#1a1812` |
| Foreground | `#d2cbbe` |
| Accent     | `#5a9db3` |
| Muted      | `#3b3b32` |
| Red        | `#b5786a` |
| Green      | `#7d9a7e` |
| Yellow     | `#c4a87a` |
| Blue       | `#3e6a7d` |
| Magenta    | `#8b7a8b` |
| Cyan       | `#5a8a94` |

## Installation

```bash
omarchy theme install https://github.com/danieldguapul/silt
omarchy theme set "Silt"
```
